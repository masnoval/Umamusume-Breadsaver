# Umamusume-Breadsaver

BreadSaver - platform web untuk menghubungkan toko roti dan pembeli.

Struktur awal ini disusun berdasarkan dokumen proyek RPL BreadSaver:
- MVC: Boundary / Control / Entity
- PHP + MySQL + Bootstrap + JavaScript
- Use case UC-01 sampai UC-12
- Database: user, produk, pesanan, detail_pesanan, rating
